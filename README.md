# 1. Общее описание
Консольное приложение на Java, имитирующее работу интерфейса командной строки (CLI) UNIX-подобной ОС.

# 2. Описание всех функций и настроек
* **Прием параметров:** Поддержка ввода путей к виртуальной файловой системе (VFS) и стартовому скрипту через аргументы командной строки.
* **Отладочный вывод:** Автоматическое отображение всех переданных параметров в консоли при запуске приложения.
* **Стартовый скрипт:** Построчное выполнение команд из файла с имитацией интерактивного диалога (ввод и вывод отображаются на экране).
* **Контроль ошибок:** Аварийная остановка работы эмулятора при первой же ошибке или неизвестной команде внутри стартового скрипта.
* **Интерактивный режим (REPL):** Переход к стандартной строке ввода после успешного завершения стартового скрипта.
* **Переменные окружения:** Раскрытие системных переменных (например, `$USERNAME`, `$COMPUTERNAME`) в любой части вводимой строки.

# 3. Описание команд для сборки проекта и запуска тестов
* **Универсальный запуск через интерактивное меню (Windows):**
  ```cmd
  run.bat
  ```
  *При запуске скрипт скомпилирует проект и предложит выбрать режим: `[1]` — Обычная интерактивная работа (через пустой скрипт) или `[2]` — Тестирование команд из файла `tests.ini`.*
* **Запуск теста обработки ошибок конфигурации:**
  ```cmd
  run_error_test.bat
  ```
* **Ручная компиляция исходного кода:**
  ```cmd
  javac src/Main.java -d out
  ```
* **Ручной запуск эмулятора с передачей параметров:**
  ```cmd
  java -cp out Main virtual_fs.zip tests/tests.ini
  ```
