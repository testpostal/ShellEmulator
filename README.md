# 1. Общее описание
Консольное приложение на Java, имитирующее работу интерфейса командной строки (CLI) UNIX-подобной ОС. Приложение поддерживает монтирование виртуальной файловой системы (VFS) из ZIP-архива напрямую в оперативную память устройства с использованием структуры `HashMap` (без распаковки файлов на жесткий диск).

# 2. Описание всех функций и настроек
* **Прием параметров:** Поддержка ввода путей к виртуальной файловой системе (VFS) и стартовому скрипту через аргументы командной строки.
* **Отладочный вывод:** Автоматическое отображение всех переданных параметров в консоли при запуске приложения.
* **Загрузка VFS в память (Этап 3):** Чтение структуры ZIP-архива, парсинг путей, сохранение содержимого текстовых файлов в оперативную память. Валидация целостности архива.
* **Стартовый скрипт:** Построчное выполнение команд из файла с имитацией интерактивного диалога (ввод и вывод отображаются на экране).
* **Контроль ошибок:** Аварийная остановка работы эмулятора при первой же ошибке (например, неверные аргументы команд) или неизвестной команде внутри стартового скрипта.
* **Интерактивный режим (REPL):** Переход к стандартной строке ввода после успешного завершения стартового скрипта.
* **Переменные окружения:** Раскрытие системных переменных (например, `$USER`, `$HOSTNAME`) в любой части вводимой строки.

# 3. Описание команд для сборки проекта и запуска тестов
Для автоматизации проверок в корне проекта созданы три скрипта реальной ОС (Windows `.bat` файлы):

* **Основное меню запуска (`run.bat`):**
  Скрипт компилирует проект и запускает эмулятор с самым большим архивом (`vfs_large.zip`). Предоставляет меню выбора режима работы:
  * `[1]` — Интерактивный режим свободного ввода (через пустой скрипт-заглушку `empty.ini`).
  * `[2]` — Основного сценарий автотестов из файла `tests.ini`.
  ```cmd
  run.bat
  ```

* **Автоматический тест трёх различных вариантов VFS (`vfs_test.bat`):**
  Специализированный скрипт для пакетного тестирования VFS. Последовательно запускает эмулятор с тремя разными ZIP-архивами (`vfs_minimal.zip`, `vfs_normal.zip`, `vfs_large.zip`), прогоняя через них общий тестовый сценарий `tests.ini`.
  ```cmd
  vfs_test.bat
  ```

* **Тестирование ошибок параметров командной строки (`run_error_test.bat`):**
  Запускает эмулятор без передачи обязательных аргументов, демонстрируя обработку критического сбоя конфигурации при старте программы.
  ```cmd
  run_error_test.bat
  ```

* **Ручная компиляция исходного кода:**
  ```cmd
  javac src/Main.java -d out
  ```

* **Ручной запуск эмулятора с передачей параметров:**
  ```cmd
  java -cp out Main vfs_large.zip tests/tests.ini
  ```
