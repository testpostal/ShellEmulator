# Эмулятор командной строки UNIX-подобной ОС

## 1. Общее описание
Консольное приложение на Java, имитирующее работу CLI UNIX. Виртуальная файловая система (VFS) загружается из ZIP-архива в память эмулятора при старте. Все модификации файлов и папок происходят в оперативной памяти устройства без изменения исходного архива.

## 2. Описание всех функций и настроек
* Чтение стартового скрипта с автоматической остановкой при первой ошибке.
* Раскрытие системных переменных окружения (например, `$USERNAME`, `$COMPUTERNAME`).
* **Поддерживаемые команды:**
  * `ls` — вывод содержимого текущего виртуального каталога.
  * `cd` — смена виртуального каталога эмулятора с поддержкой путей `.`, `..` и `/`.
  * `head` — вывод первых 10 строк текстового файла из памяти.
  * `cal` — отображение календаря на текущий месяц.
  * `mv` — перемещение или переименование объекта внутри VFS.
  * `help` — вывод справки с описанием команд.
  * `exit` — завершение работы эмулятора.

## 3. Сборка проекта и запуск тестов
Для запуска эмулятора в корне проекта находятся три командных файла Windows (.bat):
* `run.bat` — запускает меню. Выбор `1` открывает интерактивный режим (через пустой скрипт `empty.ini`), выбор `2` запускает автотесты из `tests.ini`.
* `vfs_test.bat` — запускает автотест всех команд из файла `tests.ini` последовательно для трех разных ZIP-архивов (`minimal`, `normal`, `large`).
* `run_error_test.bat` — проверяет обработку ошибки запуска без аргументов.

Компиляция исходного кода вручную:
```cmd
javac src/Main.java -d out
```

Запуск эмулятора вручную:
```cmd
java -cp out Main vfs_large.zip tests/tests.ini
```
