# Эмулятор командной строки

## 1. Общее описание
Программа на Java, имитирующая консоль UNIX. ZIP-архив файловой системы (VFS) загружается при старте прямо в память через `HashMap` без распаковки на диск.

## 2. Функции и команды (Этап 4)
* Запуск стартового скрипта с остановкой при первой ошибке.
* Поддержка переменных окружения (например, `$USER`).
* **Команды:**
  * `ls` — реальный вывод файлов и папок в текущей директории.
  * `cd` — переход по папкам (абсолютные пути, `.` и `..`) с проверкой их наличия.
  * `head <файл>` — вывод первых 10 строк текстового файла из памяти.
  * `cal` — вывод календаря на текущий месяц.
  * `exit` — выход из программы.

## 3. Сборка и запуск тестов
В корне лежат три батника для проверки:
* `run.bat` — запускает меню. Вариант 1 открывает свободную консоль (передает пустой файл `empty.ini`, чтобы обойти обязательный аргумент скрипта), Вариант 2 прогоняет автотесты из `tests.ini`.
* `vfs_test.bat` — пакетный тест. Прогоняет `tests.ini` по очереди на трех архивах (минимальный, средний, большой).
* `run_error_test.bat` — проверка падения при запуске без аргументов.

Ручной запуск:
```cmd
javac src/Main.java -d out
java -cp out Main vfs_large.zip tests/tests.ini
```
