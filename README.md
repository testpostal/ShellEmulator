# 1. Общее описание
Консольный эмулятор командной строки UNIX-подобной ОС на языке Java

# 2. Описание всех функций и настроек
* Формирование строки приглашения к вводу вида `username@hostname:~$`.
* Раскрытие системных переменных окружения в любой части строки ввода.
* Команды-заглушки `ls` и `cd` с выводом переданных аргументов.
* Контроль количества аргументов для `cd` и вывод ошибок.
* Команда `exit` для завершения работы эмулятора.

# 3. Описание команд для сборки проекта и запуска тестов
* Автоматическая сборка, тестирование из файла и запуск эмулятора (для Windows):
  ```cmd
  run.bat
  ```
* Ручная компиляция проекта:
  ```cmd
  javac src/Main.java -d out
  ```
* Ручной запуск автоматических тестов (перенаправление ввода из файла):
  ```cmd
  java -cp out Main < tests/tests.ini
  ```
* Ручной запуск эмулятора в интерактивном режиме:
  ```cmd
  java -cp out Main
  ```

# 4. Примеры использования
```text
nothing@DESKTOP-5IE91CQ:~\$ ls \$USERNAME
Команда: ls
Аргумент: nothing

nothing@DESKTOP-5IE91CQ:~\$ cd folder1 folder2
Ошибка cd: слишком много аргументов

nothing@DESKTOP-5IE91CQ:~\$ unknown_command
Ошибка: неизвестная команда unknown_command

nothing@DESKTOP-5IE91CQ:~\$ exit
```
